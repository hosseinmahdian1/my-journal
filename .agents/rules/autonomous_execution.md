# Autonomous Execution Rule

- **Autonomous Decision Making**: Execute all commands, builds, test runs, bug fixes, code edits, refactoring, and deployments proactively and autonomously without pausing to ask for user permission or confirmation at each sub-step.
- **Proactive Workstream**: Take full ownership of the requested goals, inspect files, diagnose root causes, write code, run verification commands, and deploy updates end-to-end.
- **Clear Reporting**: Summarize the completed work, verified test results, and live URLs concisely after finishing the task.
