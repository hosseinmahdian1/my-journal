# User Directives & Agent Rules

- **Full Autonomy Directive**: Always proceed autonomously with task execution, script running, file edits, testing, building, and deploying. Do NOT pause or ask for permission/confirmation before taking action.
- **Proactive Execution**: Identify root causes, make necessary code modifications, run verification tests, and deploy directly to production.
- **Concise Reporting**: Report progress and final results clearly upon completion.
